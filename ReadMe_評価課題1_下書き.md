# LE2B_〇〇_ウスイ_ナナミ　CG3 評価課題1（演出王 part2）

## 概要
クリックした場所から、5種類の3Dモデルのパーティクルが
「ぽんっ」と弾けるように広がり、逆再生のように中心へ吸い込まれて消える演出です。
自作エンジン（UN Engine / DirectX12）で制作しました。

## 操作方法
| 操作 | 内容 |
|---|---|
| 左クリック | クリックした場所からパーティクルを発生させる |
| ImGui「自動発生」 | チェックを入れると、エミッターから自動で発生し続ける |

## 実行方法
`実行ファイル` フォルダの `UnEngine.exe` をダブルクリックしてください。
（`Resources` フォルダと `dxcompiler.dll` / `dxil.dll` が同じ場所に必要です）

## こだわり（プログラム）

### 1. クリックした場所から出せるようにした
画面上のクリック位置（ピクセル）を、3D空間のどこにあたるかに変換しています。
カメラの行列を逆に使って、クリックした点からまっすぐ奥に伸ばした線を作り、
その線が画面中央の面とぶつかる場所をパーティクルの発生位置にしました。
ImGui のウィンドウを触っているときは、パーティクルが出ないようにしています。

### 2. 「ぽんっと広がって、逆再生で戻る」動き
パーティクルが生まれてから消えるまでを 0〜1 の割合で表し、
その割合から「今どこにいるか」「今どのくらいの大きさか」を毎フレーム計算しています。

- 前半：中心から外側へふわっと広がる
- 後半：前半と同じ計算を時間を逆にして使い、動画の逆再生のように中心へ戻る
- 大きさは、少しだけ大きくなりすぎてから戻るイージングで「ぽんっ」と出るようにした

### 3. 5種類の形を、まとめて軽く描画
1つずつ描くと重くなるので、Instancing（同じ形をまとめて描く仕組み）を使っています。
形が5種類あるので、データを形ごとに5つの区切りに分けて、
形ごとに1回ずつまとめて描くようにしました。

### 4. 1つずつ違う動き
飛んでいく方向・距離・形・大きさ・回転の向きと速さを、1つずつランダムに決めています。
同じクリックでも毎回ちがう見え方になります。

### 5. 自分で作ったモデルを使用
パーティクルの形は Blender で自作し、授業で導入した assimp で読み込んでいます。

## 主な実装箇所
- `project/main.cpp`
  - `MakeNewParticle`：発生時の方向・距離・形・回転・色・寿命
  - `EaseOutBack` / `EaseOutCubic`：イージング関数
  - メインループ内：クリック判定と3D座標への変換、パーティクルの更新、形ごとの描画
- `project/Resources/Particle1〜5`：パーティクルのモデル
